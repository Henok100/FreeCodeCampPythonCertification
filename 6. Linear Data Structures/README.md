# Linear Data Structures

## 📌 Overview

This topic focuses on linear data structures and how data can be organized, stored, and accessed efficiently in Python.

It introduces the concept of custom data structures and demonstrates how hashing can be used to store and retrieve data using key-value pairs.

---

## 🧠 Key Concepts Covered

- Data structures overview
- Arrays and lists (conceptual use)
- Key-value storage systems
- Hash functions
- Collision handling basics
- Dictionary-like implementations
- Data retrieval and deletion logic

## 🛠️ Certification Project

---

### 1. Build a Hash Table

**Description:**  
A custom implementation of a hash table that stores key-value pairs using a hashing function based on Unicode values. The structure supports adding, removing, and looking up values efficiently.

---

**Core Features:**

- Hash function using character Unicode values
- Add key-value pairs using hashed keys
- Handle collisions using nested dictionaries
- Remove key-value pairs safely
- Lookup values by key
- Graceful handling of missing keys

---

**Concepts used:**

- Hashing algorithms
- Dictionary-based storage
- Collision handling
- Data retrieval logic
- Function design and modular structure
- Error-safe operations
