# Dictionaries and Sets

## 📌 Overview

This topic focuses on Python's dictionary and set data structures, which are essential for managing structured data efficiently.

It includes both foundational exercises and a certification-level project that demonstrates real-world application of key-value storage and data manipulation.

---

## 🧠 Key Concepts Covered

- Python dictionaries
- Key-value data storage
- Dictionary operations (add, update, delete)
- Set-like behavior using dictionaries
- Data validation
- State management
- Error handling in data structures

## 🛠️ Labs & Certification Project

---

### 1. User Configuration Manager (Certification Project)

**Description:**  
A system that manages user settings using a dictionary-based configuration manager. It allows adding, updating, viewing, and deleting user preferences while handling validation and edge cases.

**Core Features:**
- Add new settings
- Update existing settings
- Delete settings
- View all settings in a formatted output
- Prevent duplicate keys
- Handle missing or invalid operations gracefully

**Concepts used:**
- Dictionary operations
- Key existence checks
- String formatting
- Function design and modularization
- Data validation
