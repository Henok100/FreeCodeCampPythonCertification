# Dynamic Programming

## 📌 Overview

This topic introduces dynamic programming (DP), a powerful algorithmic technique used to solve problems by breaking them into smaller subproblems and storing intermediate results to avoid repeated computations.

The focus of this topic is understanding optimization through reuse of previously computed values.

---

## 🧠 Key Concepts Covered

- Dynamic programming principles
- Overlapping subproblems
- Optimal substructure
- Iterative computation
- Sequence building
- Time complexity optimization
- Bottom-up approach

---

## 🛠️ Lab

---

### 1. Build an Nth Fibonacci Number Calculator

**Description:**  
A function that calculates the nth Fibonacci number using a dynamic programming approach. Each number is computed by summing the previous two numbers and stored in a sequence list.

---

**Core Features:**

- Initializes a sequence list with `[0, 1]`
- Iteratively builds Fibonacci sequence
- Stores computed values to avoid recomputation
- Returns the nth Fibonacci number efficiently

---

**Concepts used:**

- Dynamic programming (bottom-up approach)
- Iteration instead of recursion
- Memory optimization via caching in list
- Sequence generation
- Algorithm efficiency improvement
