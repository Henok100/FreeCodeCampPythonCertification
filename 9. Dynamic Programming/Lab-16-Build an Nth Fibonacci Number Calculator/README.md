# Nth Fibonacci Number Calculator

This project calculates the nth Fibonacci number using a dynamic programming approach.

It was completed as the final lab in the freeCodeCamp Python Certification.

---

## 📌 What is Fibonacci?

The Fibonacci sequence is:

```
0, 1, 1, 2, 3, 5, 8, 13, ...
```

Each number is the sum of the two previous numbers.

---

## ⚙️ Function

### `fibonacci(n)`

Returns the nth Fibonacci number.

### Parameters:
- `n (int)`: position in the Fibonacci sequence (0-indexed)

### Returns:
- `int`: Fibonacci number at position n

---

## 🧪 Example

```python
print(fibonacci(10))
```

---

## 📤 Output

```
55
```
