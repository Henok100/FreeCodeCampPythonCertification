# Python ISBN Validator

A Python program that validates ISBN-10 and ISBN-13 codes by calculating and verifying check digits.

This project was completed as part of the freeCodeCamp Python Certification debugging labs.

## Features

- Validates ISBN-10 codes
- Validates ISBN-13 codes
- Handles invalid input safely
- Detects incorrect formatting
- Supports ISBN-10 check digit `X`
- Uses exception handling to prevent crashes

## Concepts Practiced

- Exception handling
- Debugging
- Input validation
- String manipulation
- List comprehensions
- Algorithmic problem solving
