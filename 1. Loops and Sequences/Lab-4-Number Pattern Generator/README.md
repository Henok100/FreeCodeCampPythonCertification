# Number Pattern Generator

A Python function that generates a space-separated sequence of numbers from 1 up to a given positive integer.

This project was completed as part of the freeCodeCamp Python Certification.

## Features

- Generates number sequences dynamically
- Uses a `for` loop for pattern construction
- Validates input type and value
- Returns clear error messages for invalid input

## Example Usage

```python
print(number_pattern(4))
```

## Example Output

```text
1 2 3 4
```

## Validation Rules

- Input must be an integer
- Input must be greater than 0

## Concepts Used

- Functions
- For loops
- String manipulation
- Input validation
- Range iteration
