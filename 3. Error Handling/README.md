# Error Handling

## 📌 Overview

This topic focuses on handling runtime errors in Python programs using structured error handling techniques. It emphasizes writing robust programs that do not crash when users provide invalid input.

The main focus is on debugging existing code, identifying common errors, and ensuring graceful program behavior.

---

## 🧠 Key Concepts Covered

- Try / Except blocks
- Handling IndexError
- Handling ValueError
- Input validation
- Defensive programming
- Debugging logic errors
- String and list manipulation

## 🛠️ Lab & Projects

---

### 1. Debug an ISBN Validator

**Description:**  
A program that validates ISBN-10 and ISBN-13 codes. The task involves fixing multiple bugs and adding proper error handling so the program can safely process user input without crashing.

**Core Features:**
- Validate ISBN length (10 or 13 digits)
- Handle missing comma input safely
- Handle non-numeric length input
- Detect invalid characters in ISBN
- Compute and compare check digits
- Display appropriate validation messages

**Concepts used:**
- Exception handling (`try`, `except`)
- IndexError handling
- ValueError handling
- Input parsing and validation
- List slicing and string processing
- Debugging existing code
