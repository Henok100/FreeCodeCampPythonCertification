# Object-Oriented Programming (OOP)

## 📌 Overview

This topic focuses on advanced Object-Oriented Programming (OOP) concepts in Python. It builds on basic class usage and introduces encapsulation, inheritance, abstraction, and method overriding through structured, real-world projects.

The goal is to design scalable and reusable systems using object-oriented principles.

---

## 🧠 Key Concepts Covered

- Classes and objects
- Encapsulation and data hiding
- Properties (getters and setters)
- Method overriding
- Abstract classes
- Inheritance
- Polymorphism
- State management in objects

---

## 🛠️ Labs & Certification Project

---

### 1. Build a Game Character Stats Tracker (Lab)

**Description:**  
A system that models a game character with attributes like health, mana, and level. It includes controlled attribute access, leveling mechanics, and formatted output.

**Concepts used:**
- Encapsulation with private attributes
- Property decorators (`@property`)
- Input validation in setters
- Object state updates
- Method behavior (`level_up`)
- String representation (`__str__`)

---

### 2. Build a Player Interface (Lab)

**Description:**  
An abstract base class system that defines a generic player and implements a Pawn class with movement logic using a depth-first style approach.

**Concepts used:**
- Abstract base classes (`abc.ABC`)
- Method abstraction (`@abstractmethod`)
- Inheritance
- Random movement generation
- State tracking (position & path)
- List-based movement system

---

### 3. Build a Polygon Area Calculator (Certification Project)

**Description:**  
A full object-oriented system that models geometric shapes using Rectangle and Square classes. It supports area calculations, visual representation, and shape fitting logic.

**Core Features:**
- Rectangle class with geometric methods
- Square class inheriting from Rectangle
- Area, perimeter, and diagonal calculations
- Text-based shape rendering
- Shape containment calculation
- Method overriding and inheritance

**Concepts used:**
- Inheritance (Rectangle → Square)
- Method overriding
- Geometry calculations in OOP
- String-based visualization
- Object interaction and reuse
