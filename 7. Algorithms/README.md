# Algorithms

## 📌 Overview

This topic focuses on fundamental algorithm design and problem-solving techniques in Python. It covers numerical methods, sorting algorithms, recursion, and real-world validation logic.

The goal is to strengthen analytical thinking and implement efficient solutions to classical computer science problems.

## 🛠️ Labs & Certification Project

---

### 1. Implement the Bisection Method

**Description:**  
A numerical algorithm used to approximate square roots using iterative interval halving until a tolerance level is reached.

**Concepts used:**
- Iteration with while loops
- Numerical approximation
- Error tolerance handling
- Conditional branching

---

### 2. Implement the Quicksort Algorithm

**Description:**  
A recursive sorting algorithm that uses a pivot element to divide a list into smaller sublists and sort them efficiently.

**Concepts used:**
- Recursion
- Divide and conquer
- List partitioning
- Functional decomposition

---

### 3. Implement the Selection Sort Algorithm

**Description:**  
A simple sorting algorithm that repeatedly selects the smallest element from the unsorted portion and places it in the correct position.

**Concepts used:**
- Nested loops
- In-place sorting
- Index tracking
- Optimization awareness

---

### 4. Implement the Luhn Algorithm

**Description:**  
A validation algorithm used to verify credit card numbers using a checksum formula.

**Concepts used:**
- Digit manipulation
- String processing
- Modulo arithmetic
- Validation logic

---

## 🎓 Certification Project

---

### 5. Implement the Tower of Hanoi Algorithm

**Description:**  
A recursive puzzle-solving algorithm that moves disks between rods following strict rules. The goal is to move all disks from the starting rod to the target rod using optimal moves.

**Concepts used:**
- Recursion
- Stack-like behavior
- Problem decomposition
- State tracking
- Move sequencing logic
