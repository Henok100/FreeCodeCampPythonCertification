# Graphs and Trees

## 📌 Overview

This topic focuses on graph theory, tree structures, and advanced traversal algorithms. It introduces how data can be represented as nodes and edges and how to explore those structures using systematic search techniques.

The labs also include backtracking-based problem solving for constraint satisfaction problems.

---

## 🧠 Key Concepts Covered

- Graph representation (adjacency list and matrix)
- Graph traversal techniques
- Depth-first search (DFS)
- Stack-based exploration
- Backtracking algorithms
- Constraint satisfaction problems
- Recursive problem solving
- State space exploration

---

## 🛠️ Labs

---

### 1. Build an Adjacency List to Matrix Converter

**Description:**  
A function that converts a graph from adjacency list format into an adjacency matrix representation.

**Concepts used:**
- Graph representation formats
- 2D array construction
- Index mapping
- Data structure transformation

---

### 2. Implement the Depth-First Search Algorithm

**Description:**  
A graph traversal algorithm that explores nodes by going as deep as possible before backtracking. Implemented using a stack.

**Concepts used:**
- Stack-based traversal
- Visited node tracking
- Graph exploration
- Iterative DFS implementation
- Adjacency matrix processing

---

### 3. Implement the N-Queens Problem

**Description:**  
A classic backtracking problem where N queens must be placed on an N×N chessboard so that no two queens attack each other.

**Concepts used:**
- Backtracking algorithm
- Recursive search
- Constraint checking (rows, columns, diagonals)
- State pruning
- Combinatorial problem solving
