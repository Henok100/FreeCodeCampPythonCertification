# Classes and Objects

## 📌 Overview

This topic introduces Classes and Objectsin Python. It focuses on designing classes, creating objects, and using methods and inheritance to model real-world systems.

You also apply OOP concepts in both a simple lab and a full certification-level project.

---

## 🧠 Key Concepts Covered

- Classes and objects
- Constructors (`__init__`)
- Instance attributes and methods
- Encapsulation
- Method design
- Operator-style behavior using methods
- Inheritance (basic use)
- String representation (`__str__`)

---

## 🛠️ Labs & Certification Project

---

### 1. Build a Planet Class (Lab)

**Description:**  
A class-based system that models a planet with attributes like name, type, and star. It includes validation, string formatting, and simple behavior like orbiting.

**Concepts used:**
- Class definition
- Constructor validation
- Instance attributes
- Methods (`orbit`, `__str__`)
- Error handling (TypeError, ValueError)

---

### 2. Build a Budget App (Certification Project)

**Description:**  
A fully functional budgeting system built using classes. It allows tracking income and expenses across categories, performing transfers, and generating a visual spending chart.

**Core Features:**
- Deposit and withdraw transactions
- Balance tracking per category
- Transfers between categories
- Fund validation system
- Formatted string representation of ledger
- Spending chart visualization

**Concepts used:**
- Object-oriented design
- Data encapsulation
- Method interaction between objects
- List of dictionaries as ledger storage
- Class-based system modeling
- String formatting and reporting logic
