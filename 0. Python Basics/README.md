# Python Basics

## 📌 Overview

This topic introduces the fundamental concepts of Python programming through hands-on labs and mini projects.

The focus is on building logical thinking, writing clean code, and applying basic programming concepts such as conditionals, functions, and simple problem-solving.

---

## 🧠 Key Concepts Covered

- Variables and Data Types
- Conditional Statements (if / elif / else)
- Functions
- Input Validation
- Boolean Logic
- Basic Problem Solving

---

## 🛠️ Labs & Projects

This topic includes the following practical exercises:

---

### 1. Build a Travel Weather Planner

**Description:**  
A program that determines whether a user can commute based on weather conditions, distance, and available transportation options.

**Concepts used:**
- Conditional statements
- Boolean logic
- Multiple decision branches (if / elif / else)

---

### 2. Build an Apply Discount Function

**Description:**  
A function that calculates the final price of an item after applying a percentage discount, with validation for input values.

**Concepts used:**
- Functions
- Input validation
- Type checking
- Arithmetic operations

---

### 3. Build an RPG Character

**Description:**  
A function that creates and validates a game character with attributes such as name, strength, intelligence, and charisma.

**Concepts used:**
- Functions with multiple parameters
- Input validation rules
- String formatting
- Conditional logic
